# 复现说明

## 1. 数据

本机没有课程的 `/var/dataset`，所以自建了数据，文件格式与课程一致。

- **数据来源**：texmex 公开的 SIFT1M，`ftp://ftp.irisa.fr/local/texmex/corpus/sift.tar.gz`（168,280,445 字节，md5 b23d1b3b2ee8469d819b61ca900ef0ed）。
- **生成步骤**（约 1.5 分钟，峰值内存 1.9 GB）：

  ```bash
  mkdir -p ~/datasets/sift1m/raw && cd ~/datasets/sift1m/raw
  curl -C - -o sift.tar.gz ftp://ftp.irisa.fr/local/texmex/corpus/sift.tar.gz && tar xzf sift.tar.gz
  python3 -m venv lab2/.venv && lab2/.venv/bin/pip install faiss-cpu==1.15.1 numpy pandas matplotlib tabulate pypdf pymupdf
  lab2/.venv/bin/python -I scripts/prepare_data.py --raw ~/datasets/sift1m/raw/sift --out ~/datasets/sift1m
  ```

- **生成的文件**：`sift_base.fbin`、`sift_query.fbin`、`centroid_4096.fvecs`、`cluster_id_4096.ivecs`、`gt.ibin`。各文件的 md5 和训练参数见 `data_manifest/MANIFEST.json`。
- **使用方式**：脚本通过环境变量 `IVF_DATA` 定位数据目录，默认是 `/home/felix/datasets/sift1m`。如果用课程提供的数据，设置 `IVF_DATA=/var/dataset` 即可。

## 3. 实验（Python 用 lab2/.venv，路径不要用 realpath 解析）

| 内容 | 命令 | 输出 |
|---|---|---|
| 环境记录 | `bash scripts/env.sh` | `results/env.txt` |
| P0 分阶段画像 | `bash scripts/profile.sh` | `results/p0_*` |
| A 线程数 / 调度 / 等待策略 | `bench.py A --rounds 3`；`A_sched --rounds 2`；`A_wait --rounds 2` | `results/A*.csv` |
| B 查询顺序 | `bench.py B --rounds 3`；`bash scripts/stats_B.sh`；`python3 -I scripts/model_B.py` | `results/B*.csv`、`results/stats/` |
| C grain / cutoff | `bench.py C --rounds 3`；`C_cutoff --rounds 3` | `results/C*.csv` |
| D nprobe | `bench.py D --rounds 3` | `results/D*.csv` |
| E SIMD（区组设计） | `make ivf_lab_native`；`bench.py E_blocked --rounds 5`；`bash scripts/vecreport.sh` | `results/E_blocked.csv`、`results/vec/` |
| F std::thread | `bench.py F --rounds 3` | `results/F*.csv` |
| 读带宽 | `make bw_probe && ./bw_probe` | `results/bw_probe.csv` |
| perf | `sudo sysctl -w kernel.perf_event_paranoid=1`；`perf_ctl.py --rounds 3` | `results/perf_main_paranoid*.csv`、`results/perf_raw/` |
| 汇总与作图 | `summarize.py <实验名>`；`plot.py A C D E` | `results/*_summary.csv`、`figures/` |
| 报告 | `bash report/build.sh` | `report/report.pdf` |

表中 `bench.py`、`summarize.py`、`plot.py`、`perf_ctl.py` 都在 `scripts/` 下，用 `lab2/.venv/bin/python -I` 运行。所有命令、数据和推导过程按时间顺序记录在 `实验日志.md` 中。

## 4. 环境

- 机器：i7-14650HX（8P+8E），WSL2 内核 6.6.87.2，g++ 13.3.0，libgomp；
- 编译选项：`-O3 -std=c++17 -fopenmp -pthread`，`-march=native` 只在实验 E 使用；
- 不设置 `OMP_PROC_BIND`，CPU 集合为 0–23；
- perf 6.8.12，调用路径 `/usr/lib/linux-tools/6.8.0-147-generic/perf`。
