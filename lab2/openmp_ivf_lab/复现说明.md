# 复现说明

报告中的所有结果都在课程实验服务器上得到，使用官方数据 `/var/dataset`，原始输出在 `results/server/`。

## 1. 环境与数据

- **服务器**：Intel Xeon Gold 5218 虚拟机，32 vCPU，Ubuntu 22.04，g++ 11.4.0 + libgomp；取 P=16，大 batch=4P=64（确定依据见报告 §1）。
- **数据**：`/var/dataset` 下的 `sift_base.fbin`、`sift_query.fbin`、`gt.ibin`、`centroid_4096.fvecs`、`cluster_id_4096.ivecs`（课程提供，不随压缩包提交）。
- **数据路径**：程序和脚本默认读取 `/var/dataset`。若数据放在别处，用环境变量 `IVF_DATA` 指定。
- **编译选项**：统一使用 `-O3 -std=c++17 -fopenmp -pthread`，不加 `-ffast-math`。`-march=native` 的两种构建只在 SIMD 实验中作对照（见 `Makefile`）。
- **环境记录**：`IVF_RESULTS=results/server bash scripts/env.sh` 写入 `results/server/env.txt`。

```bash
make && make test                                    # 原始配套测试

```

## 3. 实验（在服务器上运行，建议用 `nohup … &` 放到后台）

服务器脚本默认使用 `IVF_DATA=/var/dataset`、`IVF_RESULTS=results/server`、`IVF_P=16`。

| 脚本 | 内容 | 主要输出（`results/server/`） | 报告位置 |
|---|---|---|---|
| `scripts/server_S1.sh` | native 构建检查；确定 P（只受计算限制的 omp1 探针，p 取 8、16、24、32） | `s0p_native_check.txt`、`S1.csv`、`stats/S1_*` | §1 |
| `scripts/server_S2S3.sh` | 线程扩展（吞吐与延迟场景）、统计构建、GNU time 差分 | `S2.csv`、`stats/S2_*`、`timev*`、`perf_unavailable.txt` | §3.1、§4.1、§4.3、§5 |
| `scripts/server_S4S6.sh` | 读带宽、向量化报告、SIMD × 编译选项（区组设计）、std::thread 对照 | `bw_probe.csv`、`vec/`、`S4_blocked.csv`、`S6.csv` | §3.5、§4.3 |
| `scripts/server_supp.sh` | 分阶段画像 P0、调度消融、实验 B（含统计）、实验 C、cutoff、实验 D、ASan 检查 | `p0_*`、`A_sched.csv`、`B.csv`、`stats/B_*`、`C*.csv`、`D.csv` | §1、§2、§3.2–3.4、§4.2 |
| `python3 -I scripts/bench.py S2b --rounds 3` | omp1 在 batch=1 时的对照 | `S2b.csv` | §4.1 |

单个实验也可以直接运行，例如：

```bash
IVF_RESULTS=results/server python3 -I scripts/bench.py C --rounds 3 --max-busy 2
```

`bench.py list` 可以列出全部实验。`--max-busy` 是共享服务器上的负载门控：每个进程启动前，检查其他用户此刻的可运行进程数，不超过这个值才开始运行。

## 5. 文件说明

- **代码**：
  - `ivf_student.cpp`：omp1、omp2、omp3、std::thread 的实现；
  - `ivf_simd.cpp`：SIMD 距离函数；
  - `ivf_stats.h`：统计插桩，只在 `ivf_lab_stats` 构建中生效；
  - `ivf_lab.cpp`：harness 扩展；
  - `tests/student_tests.cpp`：学生实现的测试；
  - `bw_probe.cpp`：读带宽探针。
- **原始数据**：`results/server/` 下的 `*.csv` 是每次重复的原始记录，`*_summary.csv` 是汇总结果，`.run_*.log` 是各脚本的运行日志。
- **图**：`figures/server/`。
