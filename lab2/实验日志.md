## 2026-10-25 monitor 健全性检查（临时设计，不属于变异体集合）

| 临时设计 | first_fail | 出错向量 | fail_ns |
|---|---|---|---|
| NOR 写成 NAND | 2,293,812 | op=100111 A=0 B=1 C=ffffffff ans=fffffffe | 127,464 |
| Over 不驱动（Z） | 0 | Over=z，correct 为 X | 2,424,882（全程） |

结论：monitor 能抓到普通错误，也能抓到 X/Z。NOR 段从 2,293,810 ns 开始，第 2 个向量（0 NOR 1）是第一个让 NAND 和 NOR 结果不同的向量，所以首次出错在 2,293,812 ns，与手算一致。

## 2026-10-25 激励模型与预测（在运行任何变异体仿真之前提交）

命令：`python3 scripts/tb_model.py`（27 s）。输出 `results/predictions.csv`、`results/coverage.csv`。

- 模型重放出 1,212,416 个向量，结束时刻 2,424,882 ns，与 xsim 一致。正确的逐位 CLA 模型在全部加减向量上都与参考答案相同（脚本内有 assert）。

加减各段的覆盖情况。"穿透"指进位进入某一位并被它继续传下去，"最长穿透"是连续穿透的最大位数：

| 段 | 向量 | 组间 P·C 触发 | 最长穿透 | 穿透≥4 | ≥8 | ≥16 | =32 |
|---|---|---|---|---|---|---|---|
| ADD | 262,144 | 0 | 3 | 0 | 0 | 0 | 0 |
| SUB | 262,144 | 250,642 | 32 | 251,699 | 225,679 | 130,652 | 3,266 |
| ADDU | 16,384 | 0 | 1 | 0 | 0 | 0 | 0 |
| SUBU | 16,384 | 15,684 | 32 | 15,729 | 14,461 | 10,172 | 1,250 |

- 三个移位段里 A[31:5]≠0 的向量都是 0 个；B[31]=1 的向量各有 14,336 个。

## 2026-10-25 变异测试实测（官方激励 + tb_monitor，完整跑完不中途停止）

命令：`python3 scripts/mutate.py -j 4`。4 个并行，共 33 s，结果在 `results/mutation.csv`。

- 10 个变异体的 first_fail 和 fail_ns **全部与预测精确相等**。
- 各变异体首次出错时 xsim 的实际输出：

| ID | 首次出错时的输出 | 期望值 |
|---|---|---|
| M0 | 0−0 输出 C=ffffffff | 0 |
| M1 | 0−0 输出 C=00f000f0（第 4–7 位和第 20–23 位错，即每个 cla16 的第 1 块收不到进位） | 0 |
| M2 | 0−0 输出 C=ffff0000 | 0 |
| M3 | 0x2+0x1E 输出 C=00000000 | 00000020 |
| M4 | 0−0x80000000 输出 Over=0 | 1 |
| M6 | 0x80000000>>>1 输出 C=40000000，xsim 确实按符号性规则把 `>>>` 做成了逻辑右移 | c0000000 |
| M7 | ADDU 0x20000000+0x60000000 输出 Over=1 | 0 |
| M8 | 0x08000000+0x78000000 输出 Over=0 | 1 |

- M1′ 和 M5 全程无错。
