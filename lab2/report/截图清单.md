# 截图清单

截图保存到 `lab2/report/figures/`，文件名必须和下表一致，`report.md` 按文件名引用。截好后运行 `report/build.sh` 重新生成 PDF。

## 准备

1. E 盘工程用的源码已经和仓库同步（`E:\vivado_proj\lab2_alu\src\alu.v` 与仓库里的 `src/alu.v` 相同）。如果之后改过 `src/alu.v`，先把它复制过去。
2. 打开 `E:\vivado_proj\lab2_alu\lab2_alu.xpr`，点 Flow Navigator → SIMULATION → Run Simulation → Run Behavioral Simulation。仿真时长已经设为 2500us，会自动跑到 `$finish`，大约需要几十秒。
3. 在波形窗口里把 `in1`、`in2`、`out`、`ans` 的显示进制设为十六进制（右键 → Radix → Hexadecimal），`op` 设为二进制。
